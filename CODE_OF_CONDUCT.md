# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It
applies in issues, pull requests and every other project space, and to anyone representing the project
elsewhere.

Report unacceptable behaviour to **hello@normwerk.dev**. The maintainers review every report and act on it
under the Covenant's enforcement guidelines.
