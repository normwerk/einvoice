This is the file macOS's own bundled sRGB profile stood in for during Spike B (T-031,
HOW-WE-GOT-HERE.md D-20) — that system profile was fine for local experimentation but not
licensed for vendoring into a public repository. sRGB2014.icc is: freely redistributable
(see above), the ICC's own current recommended sRGB profile, and ICC v2 format (matches
what PDF/A OutputIntent commonly expects; the v4 "preference" profiles on the same page
were not used for that reason, not because they're unlicensed — same license terms apply
to those too).
