## Internal references

Code comments and commit messages in this repository sometimes carry a short reference — a letter, a hyphen
and a number — into the maintainer's planning log, which is not public. They record why a change was made
and when; nothing in them is needed to use the packages or to work on the code.

Everything a reader sees says what it means in full instead: these documentation pages, error messages, log
lines and package descriptions never use such references. The reference pages normwerk.dev generates from
the source — the plugin's options and its error classes — show the source's doc comments with the
references removed. If something here is unclear without context you don't have, that is a documentation
bug: please open an issue.
