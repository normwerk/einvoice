## Internal references

Identifiers like `T-013`, `M-006`, `D-20`, and section references like `plan-v0.1 §3.2` point to the
maintainer's internal planning log, which is not public. They are kept for traceability — they record _why_
a decision was made and when. The decision itself, and everything needed to work on this repository, is
always documented here. A reference you cannot resolve is context you do not need; if something in these
docs is unclear without it, that is a documentation bug — please open an issue.
